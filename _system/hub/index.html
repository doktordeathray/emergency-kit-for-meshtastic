Meshtastic Emergency USB

Everything runs from this drive. No internet needed.

This browser can't talk to radios over USB. Open this page in Google Chrome or Microsoft Edge (Brave/Opera/Chromium also work). Safari and Firefox can only read the guides.
No Chrome or Edge on this computer? Go to the Meshtastic window and type C to install the free Chromium browser from this drive (Mac and Linux; Windows already has Edge).

Other things this drive can do

Go back to the Meshtastic Emergency USB window (the black window that opened first) and type a number:

  • 2 Install the Meshtastic app on this computer (Windows, Mac, Linux)
  • 3 Put the Meshtastic app on an Android phone
  • 4 Make a Raspberry Pi SD card
  • 6 Radio not detected on Windows? Install USB drivers
  • C Install the Chromium browser (if this computer has no Chrome or Edge)
  • U Update this drive with the newest firmware and apps (needs internet)

Closing that window stops the apps on this page.
