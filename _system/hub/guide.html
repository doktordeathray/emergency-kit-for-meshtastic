Quick start

  1. Plug this USB drive into a computer.
  2. Open the drive and double-click the start file for your computer:
    WindowsSTART-HERE-WINDOWS.bat
    MacSTART-HERE-MAC.command
    LinuxSTART-HERE-LINUX.sh: right-click it and choose Run as a Program (or Run in Terminal)
  3. A black window opens, then your browser opens the start page. Leave the black window open.
  4. Brand-new radio? Click Flash or update a radio first. Already running Meshtastic? Click Use Meshtastic.
  5. In the web app, click Add Connection, choose Serial (USB cable) or Bluetooth, and pick your radio.
  6. Set your region (e.g. US, EU_868, ANZ) in Settings → LoRa. The radio won't transmit until you do.
Use Google Chrome, Microsoft Edge or Chromium (Brave and Opera also work). Safari and Firefox can't connect to radios. Every Windows PC has Edge. On a Mac or Linux computer without one, the launcher offers to install the free Chromium browser from this drive. You can also type C in the black window.
Windows: a "Windows protected your PC" box may appear. Click More info → Run anyway. Mac: if it says the file "may contain malware" or "can't be opened", open Terminal, type bash and a space, drag the file into the window and press Enter. (Drives made by setup don't have this problem.)

Flash (install or update) a radio

First find which kind of radio you have:

A. ESP32 radios: web flasher

  1. Plug the radio into the computer with a data USB cable (some cables only charge; if nothing happens, try another).
  2. Start page → Flash or update a radio.
  3. 1 Device: pick your radio (or click Auto-detect if it already runs Meshtastic).
  4. 2 Firmware: pick the version marked Beta (stable). Alpha is newer but experimental.
  5. 3 Flash: choose Update to keep settings, or tick Full Erase and Install for a new or broken radio. Click Flash, choose the radio's port in the pop-up, and wait for 100%.
Port doesn't appear? Hold the radio's BOOT (or PRG) button while plugging it in, then try again. On Windows, install the USB driver: menu option 6 in the black window.

B. nRF52 and RP2040 radios: drag and drop

  1. Plug the radio in, then double-press its reset button quickly. A new drive appears (named like RAK4631, TECHOBOOT, T1000-E or RPI-RP2). On a Pico, hold BOOTSEL while plugging it in.
  2. Start page → Firmware files → choose a version (pick stable if unsure). The page lists every drag-and-drop radio by name: type your radio's name in the search box and click Download. (You can also use the web flasher: it lets you download the right file.)
  3. Drag that .uf2 file onto the new drive. The radio reboots by itself when it's done. A "disk not ejected" warning is normal.
nRF52 radio acting strangely after an update? The firmware page has factory erase files and explains which one fits your radio. Copy it the same way, then copy the firmware again.

C. Backup method: command line (ESP32)

For experts, if the browser flasher can't be used: esptool for every OS is in _system/tools/esptool, and each firmware folder contains Meshtastic's device-install / device-update scripts.

Phones

Android

The Android app is on this drive in 2-Android-Phone. In the black window choose 3, then:

  • Over Wi-Fi (easiest): phone and computer on the same Wi-Fi or the phone's hotspot. Scan the QR code, tap the .apk, then allow "install unknown apps".
  • USB cable: needs "USB debugging" turned on in the phone's Developer options (instructions are on screen).
  • Copy the file: copy the .apk to the phone any way you like (USB file transfer, SD card, another phone), then tap it in the Files app.

Once the app is on one phone, it can be shared to other phones with any file-sharing app, or the phone's "Nearby Share / Quick Share".

iPhone / iPad

Apple doesn't allow installing apps from files. iPhone users need the Meshtastic app from the App Store (install it before an emergency!). They can also use a computer with this drive.

Desktop app (optional)

An optional extra. If this kit was set up without it, the menu tells you how to add it.

The web app on the start page does everything you need. For a stand-alone app, choose 2 in the black window. It installs the official Meshtastic Desktop app:

  • Windows: a normal installer opens. Click through it. Then find "Meshtastic" in the Start menu.
  • Mac: copied to Applications automatically. (Built for Apple-chip Macs; on older Intel Macs use the web app.)
  • Linux: copied to ~/Applications and added to your app menu (64-bit Intel/AMD and ARM).

The installers are also in 1-Desktop-App if you'd rather run them yourself.

Offline map

If this drive has the offline map extra, the web app's map shows the area chosen in setup, with no internet. Outside that area the map is blank. To choose a different or bigger area, run SETUP again on this drive while you have internet. The map refreshes itself every few months when you press U.

Raspberry Pi

An optional extra. If this kit was set up without it, the menu tells you how to add it.

Turns a Raspberry Pi with a LoRa radio HAT (or a USB radio) into a Meshtastic node. Works on Pi 3, 4, 5, 400, 500 and Zero 2 W (64-bit models). You need a microSD card of 8 GB or larger and a card reader.

Writing the card erases everything on it. Double-check you pick the SD card, not this USB drive or another disk.

Option A: Ready-made Meshtastic image (mPWRD-OS)

Everything is preinstalled. Note: this project is still new (alpha).

  1. Black window → 4 → 1 opens Raspberry Pi Imager.
  2. Choose your Raspberry Pi model. Under Operating System, scroll to the bottom and choose Use custom. Open the drive's 3-Raspberry-Pi/Option-A-… folder and pick the .img.xz file.
  3. Choose your SD card. If asked about customisation, choose No (this image does its own setup). Write.
  4. Put the card in the Pi, connect a network cable (or keyboard + screen), and power it on.
  5. Log in as root, password 1234. You'll be asked to choose a new password. Then type mpwrd-menu to pick your radio and settings.

Option B: Official Raspberry Pi OS + Meshtastic

  1. Black window → 4 → 1 opens Raspberry Pi Imager.
  2. Choose your Pi model → Use custom → the .img.xz in 3-Raspberry-Pi/Option-B-….
  3. Choose the SD card. When asked to customise, say Yes / Edit settings and set: a username and password, your Wi-Fi (optional), and turn on SSH. Write.
  4. When it finishes, take the card out and put it back in. Then in the black window choose 4 → 2. This copies the Meshtastic package onto the card and switches on the radio HAT connections.
  5. Put the card in the Pi and power it on. Wait 2-3 minutes, then log in with keyboard + screen, or from another computer with ssh username@pi-address.
  6. Type: 
    sudo bash /boot/firmware/meshtastic/install.sh
    It installs Meshtastic (no internet needed), asks which radio you have, and starts it.
  7. When it's done it shows an address like https://192.168.1.50:9443. Open it in a browser on any device on the same network to use the Pi's own web app (accept the security warning; the Pi uses a self-signed certificate). The phone and desktop apps can also connect to the Pi over the network.
Imager will show a "Use custom" option even without internet. The list of other operating systems needs internet, so ignore it.

Troubleshooting

ProblemFix
Nothing happens when I double-click the start fileWindows: right-click → Run as administrator isn't needed, but try right-click → Open. Mac and Linux: open a Terminal, type bash (with a space), drag the file in, and press Enter. This also gets round the Mac's "may contain malware" message.
Browser shows "This site can't be reached"The black window was closed. Start it again.
"This browser can't talk to radios"Use Chrome, Edge or Chromium. No such browser? Type C in the black window to install Chromium from this drive (Mac/Linux).
Chromium won't open on a MacTry to open it once, then go to System Settings → Privacy & Security, scroll down and click Open Anyway.
No radio in the port listTry a different USB cable (many are charge-only) and a different USB port. Windows: install drivers (black window option 6). Linux: run sudo usermod -aG dialout $USER, then log out and in.
Flashing fails part-wayHold the BOOT button while plugging in, then flash again with Full Erase. Close any other app using the radio (the desktop app, Arduino, etc.).
The map is emptyMap pictures come from the internet, so they're blank offline. Node positions and distances still work.
Radio won't send messagesSet the Region in Settings → LoRa. All radios must use the same region and channel settings.
Pi: the copy step can't find the SD cardTake the card out and put it back in. Look for a drive named bootfs. Windows: if it asks to format a disk, click Cancel.

Making more drives (or installing on a computer / Raspberry Pi)

Easiest: in the black window, type K (Copy this kit to another USB or external drive). Plug in the other drive, pick it, and choose The same as this drive: everything is copied, with no internet needed. Or:

Run the setup file for this computer: double-click SETUP-WINDOWS.bat or SETUP-MAC.command, or on Linux right-click SETUP-LINUX.sh and choose Run as a Program. (On a finished drive the Mac file opens with a double-click. If you're running it from a freshly downloaded setup zip, macOS blocks that: open Terminal, type bash and a space, drag SETUP-MAC.command into the window and press Enter.) It asks where (a USB drive, this computer, or a Raspberry Pi) and what: the standard kit (~1.5 GB: web app, flasher + firmware, Android app, browser), optionally plus extras you pick, such as the desktop apps or Raspberry Pi images. Parts this drive already has are copied, so making a copy needs no internet. Anything else is downloaded.

To share the kit with others, send the small setup zip (a few MB) instead of a whole drive. They run SETUP once with internet.

Meshtastic documentation

The start page has a Meshtastic documentation section: a full offline copy of meshtastic.org/docs (getting started, every setting, supported radios, apps, FAQ). It's built from the docs' open-source code (GPL-3.0) without online search or usage tracking; links to Meshtastic's online flasher and web app go to the copies on this drive. Pressing U brings it up to date.

Keeping it up to date

Whenever you have internet, plug the drive in, start it as usual, and type U in the black window. It shows what's new, including a newer version of this kit (start windows, setup, guides), asks once, then downloads straight onto the drive. After a kit update, it offers to restart the black window so the new version takes over (you can also type R any time) (10-30 minutes; don't unplug it while it runs). Works on Windows, Mac and Linux. Nothing needs installing: the drive carries its own copy of Python.

The start page also checks by itself when the computer is online, and shows a green banner if there's something newer.

Use a drive of 4 GB or more (8 GB or more if you add extras or want room for updates). The best format is exFAT, which works on Windows, Mac, Linux and Raspberry Pi. If the drive you pick isn't exFAT, setup shows what's on it and offers to erase it and format it as exFAT. It only erases after you type ERASE, and you can keep the drive as it is instead. (Windows asks for admin permission to format; Linux asks for your password.)
