Set up Meshtastic when there's no internet.

Flash new radios and install the Meshtastic app on phones and computers, with optional extras for building a Raspberry Pi node. This kit downloads what those jobs need onto a USB drive while you still have a connection, so you can do them anywhere later.

FIG. 1 · FLASHING A RADIO, NO NETWORK

Meshtastic radios talk to each other without the internet. Getting them set up does need it: the flasher, the firmware and the apps all download at the moment you use them. When the network is down, or you're out of range, a new radio is a blank circuit board.

What this kit does about it: it saves the official tools and releases onto a USB drive ahead of time, and runs them from the drive.

What it changes: nothing in the firmware or apps. They're official releases, used as published. The one exception is Meshtastic's web flasher, which is rebuilt with small changes so it reads firmware from the drive instead of the internet.

Before

While you still have internet

  1. 1

    Download the setup kit and unzip it

    It's 5.3 MB. Before you open it, check it's genuine, which takes about a minute. Then run the setup file for the computer you're on.

    SETUP-WINDOWS.batWindows 10 / 11. Double-click it.
    SETUP-MAC.commandmacOS. Don't double-click it: run it from Terminal (see below).
    SETUP-LINUX.shLinux and Raspberry Pi. Right-click it and choose Run as a Program, or type bash SETUP-LINUX.sh in a terminal.

    On a Mac: macOS won't let you double-click a downloaded script. Instead, open Terminal (Cmd + Space, type Terminal, press Enter), type bash and a space, drag SETUP-MAC.command into the window, and press Enter. You only need to do this once.

  2. 2

    Answer two questions

    Where: a USB drive (setup lists the ones plugged in), this computer, or this Raspberry Pi. What: the standard kit, or the standard kit plus extras you pick. Setup then downloads the current releases from their official sources. That takes 15 to 60 minutes, depending on your connection.

  3. 3

    Make copies

    Run setup on a finished drive to copy it to another USB stick. Parts it already has are copied, so no download is needed. Give one to everyone in your group.

No internet

When there's no connection

  1. 1

    Plug the drive into any computer and open START-HERE

    Double-click START-HERE-WINDOWS.bat or START-HERE-MAC.command. On Linux, right-click START-HERE-LINUX.sh and choose Run as a Program. A small window opens with a menu like this, then your browser opens. Leave the window open while you work.

    1Open Meshtastic in the browser
    2Install the Meshtastic app on this computer
    3Put the Meshtastic app on an Android phone
    4Make a Raspberry Pi SD card
    6Install USB drivers for radios (Windows)
    CInstall a browser that works with radios (Mac, Linux)
    UUpdate this drive (when you're online again)
  2. 2

    Flash the radio

    Plug the radio in with a data cable and pick it in the flasher, which runs from the drive. Boards such as the Heltec V3 and T-Beam flash in the browser. RAK4631, T-Echo and Pico boards take a .uf2 file dropped onto them.

  3. 3

    Set the region, then get phones on

    A radio won't transmit until its region is set (US, EU_868, ANZ and others). Then phones on the same Wi-Fi or hotspot scan a QR code to install the Android app from the drive.

Check your download is genuine

Every file has a fingerprint, a long code called a SHA-256 checksum, worked out from every byte inside it. If even one byte changes, whether from a broken download or from someone tampering with it, the fingerprint comes out completely different.

So if your file's fingerprint matches the one published here, you have exactly the file we published. This takes about a minute and you only need one of the three ways below.

Use your computer's built-in tools

Each computer can make a fingerprint by itself.

Windows

  1. Open your Downloads folder in File Explorer.
  2. Click in the address bar at the top, type powershell and press Enter. A blue or black window opens in that folder.
  3. Paste this and press Enter:
    Get-FileHash .\Meshtastic-Emergency-Kit-Setup.zip
  4. The long code under Hash is the fingerprint. Capital letters don't matter.

Mac

  1. Press Cmd + Space, type Terminal and press Enter.
  2. Paste this, with the space at the end, but don't press Enter yet:
    shasum -a 256
  3. Drag the zip from your Downloads folder into the Terminal window. Its location fills in. Now press Enter.
  4. The long code at the start of the line is the fingerprint.

Linux / Raspberry Pi

  1. Open your Downloads folder, right-click an empty spot and choose Open in Terminal. (Or open a terminal and type cd ~/Downloads.)
  2. Paste this and press Enter:
    sha256sum Meshtastic-Emergency-Kit-Setup.zip
  3. The long code at the start of the line is the fingerprint.
If it doesn't match

Don't open the file. Delete it, download it again from this page, and check again. A download that was cut short is the usual cause. If a fresh download still doesn't match, it isn't the published file, so don't use it.

Questions

Is this an official Meshtastic product?

No. It's an independent community project, not made or endorsed by Meshtastic LLC. Setup downloads official Meshtastic firmware and apps from Meshtastic's own releases and uses them unchanged. The web flasher is Meshtastic's, rebuilt to work offline (see below).

Who made this?

It's a collaboration between doktordeathray and Claude Code, Anthropic's AI coding assistant. AI wrote most of the scripts, the offline guide and this page, with a person deciding what to build, testing it and reviewing the results.

When do I need internet?

Once, to prepare the drive, and later only if you want updates. Flashing radios and installing the apps works from the drive with no connection. Meshtastic itself never needs it.

Why is the download so small?

The setup kit holds the launchers, guides and scripts, plus one piece from another project: Meshtastic's web flasher, rebuilt for offline use. Firmware, apps, the browser and the Raspberry Pi images download on your own computer from each official source.

What was changed in the web flasher?

Three things, all to make it work offline: it reads firmware and the board list from the drive instead of Meshtastic's servers, and its usage tracking is removed. The flasher is GPL-3.0 licensed. Its licence, the exact source version and a list of the changes are in the kit's _system/flasher folder.

Is it finished?

It's an early release. Everything has been built and tested on a Mac. Windows, Linux and Raspberry Pi have been checked by reading the scripts, not yet on real machines, so try your drive on each kind of computer you plan to use. Report problems on GitHub.

How do I keep it current?

Plug the drive into any computer that's online, start it and press U. It lists what's new, asks once, then downloads straight onto the drive.

What size and format of USB drive?

4 GB or more for the standard kit, 8 GB or more with extras. Any format will do to start: if the drive isn't exFAT (the format every computer can read), setup shows what's on it and offers to erase it and format it as exFAT. Nothing is erased unless you type ERASE.

My Mac says the file "may contain malware"

macOS blocks double-clicking any script downloaded from the internet unless it's signed with a paid Apple developer certificate, which this kit isn't. Run it from Terminal instead: open Terminal (Cmd + Space, type Terminal, press Enter), type bash and a space, drag SETUP-MAC.command into the window, and press Enter. Setup removes the block from everything it installs, so START-HERE-MAC.command on your finished drive opens with a normal double-click.

Are the Windows USB drivers safe?

Before installing a driver, the kit checks its digital signature, the maker's tamper-proof seal. The CH340 driver must be signed by its maker, WCH (Nanjing Qinheng Microelectronics). The CP210x driver must carry Microsoft's WHQL certification, and Windows refuses any driver file that doesn't match it. If a check fails, the kit won't install the file. This works for whatever version the makers release, so there's nothing to keep up to date.

For extra reassurance, the versions current in November 2026 were also looked up on VirusTotal: CH340 driver, 0 of 70 scanners flagged it, and CP210x driver, 0 of 47.

Found a problem, or have an idea?

Open an issue on GitHub: github.com/doktordeathray/emergency-kit-for-meshtastic/issues. You'll need a free GitHub account. Click New issue and tell us:

  • which computer you used (Windows, Mac, Linux or Raspberry Pi, and the version if you know it)
  • which step you were on, and what you clicked or typed
  • what you expected, and what happened instead, with any error message copied in or a screenshot
  • your radio model, if it's about flashing

Reports from Windows, Linux and Raspberry Pi are especially useful, since those haven't been tested on real machines yet. Please check the existing issues first in case someone has already reported it.

How do I check the setup kit is genuine?

Compare its fingerprint (SHA-256 checksum) with the published one. The Check your download section shows three ways, including one where you just drag the file onto the page.
